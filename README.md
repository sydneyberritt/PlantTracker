# PlantTracker
 
PlantTracker is an Android app that helps plant owners stay on top of their plant care routines. It features plant search powered by the Perenual API, personalized plant collections, and a dashboard that tells you exactly when each plant needs watering. Built with Android SDK, Firebase (Authentication & Realtime Database), and the Perenual API.
